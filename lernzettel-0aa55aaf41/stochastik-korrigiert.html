Blatt 1 von 4 · Ereignisse, bedingte Wahrscheinlichkeit und Zählen

Ereignisse und Grundregeln

Ω: Ergebnismenge; A ⊆ Ω: Ereignis; A̅: Gegenereignis.

P(Ω) = 1,  P(A̅) = 1 − P(A)
P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

Disjunkt (A ∩ B = ∅): P(A ∪ B) = P(A) + P(B).

Laplace-Experiment: P(A) = |A| / |Ω| („günstige durch mögliche“).

Gegenereignis nutzen: „mindestens einmal“ = 1 − P(keinmal).

Bedingte Wahrscheinlichkeit

PB(A) = P(A|B) = P(A ∩ B)P(B),  P(B) > 0
P(A ∩ B) = P(B) · P(A|B)

Die Bedingung B schränkt die betrachtete Ergebnismenge auf B ein. Im Baum stehen ab der 2. Stufe bedingte Wahrscheinlichkeiten.

Schreibweise PB(A) und P(A|B) bedeuten dasselbe.

Baumdiagramm, Unabhängigkeit und Satz von Bayes

Pfadregeln

  • 1. Pfadregel: entlang eines Pfads multiplizieren: P(A ∩ B) = P(A) · P(B|A).
  • 2. Pfadregel: Pfade, die zum Ereignis gehören, addieren. Totale Wahrscheinlichkeit: P(B) = P(A)·P(B|A) + P(A̅)·P(B|A̅).
  • Kontrolle: Die Äste einer Verzweigung ergeben zusammen 1.

Unabhängigkeit und Bayes

A, B unabhängig ⇔ P(A ∩ B) = P(A) · P(B)

Gleichwertig: P(A|B) = P(A). Unabhängig ≠ disjunkt (disjunkte Ereignisse mit P > 0 sind sogar abhängig).

P(A|B) = P(A) · P(B|A)P(B)

Bayes kehrt die Bedingung um („umgekehrter Baum“); P(B) mit der 2. Pfadregel berechnen.

Typischer Denkfehler: P(A|B) ≠ P(B|A). Bei Tests und Diagnosen: P(krank | positiv) ist meist viel kleiner als P(positiv | krank), wenn die Krankheit selten ist.

Kombinatorik (Ziehen von k aus n)

Mit Zurücklegen, Reihenfolge wichtignk  (z. B. 4-stellige PIN: 10⁴)
Ohne Zurücklegen, Reihenfolge wichtign · (n−1) · … · (n−k+1) = n! / (n−k)!
Ohne Zurücklegen, Reihenfolge egal(n über k) = n! / (k! · (n−k)!)  (z. B. Lotto 6 aus 49)
Alle n anordnen (Permutation)n!  (0! = 1)

Erst fragen: Mit oder ohne Zurücklegen? Spielt die Reihenfolge eine Rolle?

Zufallsgrößen und Binomialverteilung

Blatt 2 von 4 · Kennwerte, Bernoulli-Kette und typische Fragestellungen

Zufallsgröße, Erwartungswert, Streuung

Verteilung und Erwartungswert

X ordnet jedem Ergebnis eine Zahl zu. Wahrscheinlichkeitsverteilung: Tabelle xᵢ | P(X = xᵢ), Summe = 1.

E(X) = μ = Σ xᵢ · P(X = xᵢ)

Langfristiger Mittelwert; muss kein möglicher Wert sein. Faires Spiel: E(Gewinn) = 0 (Einsatz abziehen!).

Varianz und Standardabweichung

V(X) = Σ (xᵢ − μ)² · P(X = xᵢ),  σ = √V(X)
E(aX + b) = a·E(X) + b,  V(aX + b) = a²·V(X)

σ hat dieselbe Einheit wie X und misst die typische Abweichung von μ.

Binomialverteilung B(n; p)

P(X = k) = (n über k) · pk · (1 − p)n−k,  k = 0, 1, …, n

Wann binomial? (Bernoulli-Kette)

  1. Feste Anzahl n von Versuchen.
  2. Je Versuch nur zwei Ausgänge: Treffer oder Niete.
  3. Trefferwahrscheinlichkeit p konstant.
  4. Versuche unabhängig (z. B. mit Zurücklegen).

In Begründungen diese Punkte im Sachkontext nennen; bei „ohne Zurücklegen“ aus großer Grundgesamtheit: „näherungsweise binomialverteilt“.

Kennwerte

μ = E(X) = n · p
V(X) = n · p · (1 − p),  σ = √(n · p · (1 − p))

Die Verteilung hat ihr Maximum in der Nähe von n·p; für p = 0,5 ist sie symmetrisch.

Formulierungen übersetzen (Taschenrechner: binomcdf = P(X ≤ k))

genau kP(X = k)
höchstens kP(X ≤ k)
weniger als kP(X ≤ k − 1)
mindestens kP(X ≥ k) = 1 − P(X ≤ k − 1)
mehr als kP(X > k) = 1 − P(X ≤ k)
zwischen a und b (einschließlich)P(a ≤ X ≤ b) = P(X ≤ b) − P(X ≤ a − 1)
Randwerte genau beachten: „mindestens 5“ enthält 5, „mehr als 5“ beginnt bei 6.

„Mindestens-mindestens“-Aufgabe

Wie oft muss man mindestens ziehen, damit mit Wahrscheinlichkeit mindestens P0 mindestens ein Treffer dabei ist?

1 − (1 − p)n ≥ P0  ⇔  (1 − p)n ≤ 1 − P0  ⇔  n ≥ ln(1 − P0)ln(1 − p)

Beim Teilen durch ln(1 − p) < 0 dreht sich das Ungleichheitszeichen! Beispiel: p = 0,1, P0 = 0,9: n ≥ ln 0,1 / ln 0,9 ≈ 21,85 ⇒ n = 22 (Probe: 1 − 0,9²² ≈ 0,902).

Hypergeometrische und Normalverteilung

Blatt 3 von 4 · Ziehen ohne Zurücklegen, stetige Zufallsgrößen, Sigma-Regeln

Ohne Zurücklegen: hypergeometrische Verteilung

Modell

N Objekte, davon K „Treffer“; n werden ohne Zurücklegen gezogen. X = Anzahl Treffer.

P(X = k) = (K über k) · (N−K über n−k)(N über n)

„Treffer auswählen · Nieten auswählen / alle Auswahlen“. Gilt für max(0; n−(N−K)) ≤ k ≤ min(n; K).

Kennwerte und Näherung

E(X) = n · KN
V(X) = n · KN · (1 − KN) · N − nN − 1

Der Faktor (N − n)/(N − 1) < 1: kleinere Streuung als im Binomialmodell. Ist N groß gegenüber n, gilt näherungsweise B(n; K/N).

Stetige Zufallsgrößen und Normalverteilung

Dichtefunktion

Eine Dichte f mit f(x) ≥ 0 und ∫ f(x) dx = 1 (über ganz ℝ) beschreibt eine stetige Zufallsgröße:

P(a ≤ X ≤ b) = ∫ab f(x) dx,  P(X = a) = 0

Daher ist bei stetigem X egal, ob ≤ oder <.

Normalverteilung N(μ; σ)

φμ;σ(x) = 1σ√(2π) · e−(x−μ)²/(2σ²)

Glockenkurve, symmetrisch zu x = μ (Maximum), Wendestellen bei μ ± σ. Größeres σ: flacher und breiter.

P(a ≤ X ≤ b): normalcdf(a, b, μ, σ)

Standardisieren: Z = (X − μ)/σ ~ N(0; 1), P(X ≤ x) = Φ((x − μ)/σ), Φ(−z) = 1 − Φ(z). Quantil: P(X ≤ x) = r ⇒ x = invNorm(r, μ, σ).

Exakt für die Normalverteilung; für die Binomialverteilung gute Näherung, wenn die Laplace-Bedingung σ > 3 erfüllt ist. Bei B(n; p) die Grenzen auf ganze Zahlen runden: untere Grenze aufrunden, obere abrunden (Intervall „nach innen“).

Binomialverteilung durch Normalverteilung annähern

Bei σ = √(n·p·(1−p)) > 3: B(n; p) ≈ N(μ = n·p; σ). Stetigkeitskorrektur für ganzzahliges X:

P(X ≤ k) ≈ P(Y ≤ k + 0,5),  P(X ≥ k) ≈ P(Y ≥ k − 0,5),  P(X = k) ≈ P(k − 0,5 ≤ Y ≤ k + 0,5)
Wichtig: Wenn der Taschenrechner binomcdf kann, ist die exakte Binomialrechnung immer erlaubt und genauer. Die Näherung nur verwenden, wenn sie verlangt ist.

Hypothesentests

Blatt 4 von 4 · Entscheidungsregel, Fehlerarten und Teststärke

Vorgehen beim Binomialtest

  1. Testgröße: X = Anzahl der Treffer bei n Versuchen, unter H₀ X ~ B(n; p₀).
  2. Hypothesen: H₀: p = p₀ (oder p ≤ p₀ bzw. p ≥ p₀) und H₁: p > p₀, p < p₀ oder p ≠ p₀. Gerechnet wird immer mit p₀.
  3. Signifikanzniveau α (z. B. 5 %) vorher festlegen.
  4. Ablehnungsbereich K bestimmen: Pp₀(X ∈ K) ≤ α, K möglichst groß.
  5. Entscheidungsregel formulieren und im Sachzusammenhang deuten.

Rechtsseitig: H₁: p > p₀

Viele Treffer sprechen gegen H₀. Kleinstes k mit

P(X ≥ k) ≤ α ⇔ P(X ≤ k − 1) ≥ 1 − α

Ablehnungsbereich K = {k; …; n}.

Linksseitig: H₁: p < p₀

Wenige Treffer sprechen gegen H₀. Größtes k mit

P(X ≤ k) ≤ α

Ablehnungsbereich K = {0; …; k}.

Zweiseitig (H₁: p ≠ p₀): α auf beide Seiten verteilen: größtes k₁ mit P(X ≤ k₁) ≤ α/2 und kleinstes k₂ mit P(X ≥ k₂) ≤ α/2. K = {0; …; k₁} ∪ {k₂; …; n}.

Beispiel: n = 50, H₀: p = 0,3, H₁: p > 0,3, α = 5 %.  P(X ≥ 20) ≈ 0,085 > 0,05, aber P(X ≥ 21) ≈ 0,048 ≤ 0,05 ⇒ K = {21; …; 50}. Bei 21 oder mehr Treffern wird H₀ abgelehnt.
Fehler 2. Art für p₁ = 0,45: β = P0,45(X ≤ 20) ≈ 0,286; Teststärke 1 − β ≈ 0,714.

Fehlerarten und Teststärke

H₀ ist wahrH₁ ist wahr
H₀ wird abgelehntFehler 1. Art (≤ α)richtig (Teststärke 1 − β)
H₀ wird nicht abgelehntrichtigFehler 2. Art (β)

Berechnen

  • Fehler 1. Art: α' = Pp₀(X ∈ K) – das tatsächliche Niveau ist oft kleiner als α.
  • Fehler 2. Art: β = Pp₁(X ∉ K) – nur für ein konkretes p₁ berechenbar.

Zusammenhänge

  • Kleineres α ⇒ kleinerer Ablehnungsbereich ⇒ größeres β.
  • Größeres n ⇒ bei gleichem α meist kleineres β.
  • Je weiter p₁ von p₀ entfernt, desto kleiner β.

Interpretation

  • Wahl von H₀: Der Fehler, der schlimmere Folgen hätte, soll der Fehler 1. Art sein (nur er ist durch α begrenzt). Was man nachweisen will, gehört in H₁.
  • „H₀ wird nicht abgelehnt“ heißt nicht, dass H₀ bewiesen ist – die Daten sprechen nur nicht deutlich genug dagegen.
  • Antwortsatz: Entscheidung + Signifikanzniveau + Bedeutung im Sachkontext.
