Ableitungsregeln

(u ± v)' = u' ± v'    (c·u)' = c·u'
Produktregel: (u·v)' = u'·v + u·v'
Quotientenregel: (u/v)' = (u'·v − u·v') / v²
Kettenregel: (f(g(x)))' = f'(g(x))·g'(x)

„Äußere Ableitung mal innere Ableitung.“ Quotientenregel: im Zähler minus, Reihenfolge u'v zuerst!

Grenzwerte und Asymptoten

„e gewinnt“ – wichtige Grenzwerte

  • xn·e−x → 0 für x → ∞ (ex wächst schneller als jede Potenz).
  • ex → 0 für x → −∞, also auch xn·ex → 0.
  • ln(x)/x → 0 für x → ∞; x·ln(x) → 0 für x → 0⁺; ln x → −∞ für x → 0⁺.
  • Ganzrationale Funktion: Verhalten für x → ±∞ bestimmt der Summand mit der höchsten Potenz.

Gebrochen-rationale Funktion f = Z/N

  • Polstelle: N(x₀) = 0, Z(x₀) ≠ 0 → senkrechte Asymptote x = x₀. Ungerade Vielfachheit: Vorzeichenwechsel.
  • Z(x₀) = 0 und N(x₀) = 0: kürzen → evtl. hebbare Lücke.
  • Grad Z < Grad N: Asymptote y = 0.
  • Grad Z = Grad N: y = Quotient der Leitkoeffizienten.
  • Grad Z = Grad N + 1: schiefe Asymptote (Polynomdivision).

Kurvendiskussion: Reihenfolge

1. DefinitionsbereichNenner ≠ 0, Argument von ln > 0, unter der Wurzel ≥ 0.
2. Symmetrief(−x) = f(x): achsensymmetrisch zur y-Achse; f(−x) = −f(x): punktsymmetrisch zum Ursprung. Ganzrational: nur gerade bzw. nur ungerade Exponenten.
3. AchsenschnittpunkteNullstellen: f(x) = 0 (Ausklammern, Satz vom Nullprodukt, Substitution z = x², pq-Formel). y-Achse: f(0). ex ist nie 0!
4. Grenzverhaltenx → ±∞ und an Definitionslücken; Asymptoten angeben.
5. Extrempunktef'(x) = 0 und Nachweis (siehe Blatt 2), y-Koordinate mit f berechnen.
6. Wendepunktef''(x) = 0 und Nachweis, y-Koordinate mit f berechnen.
7. SkizzeAlle Punkte und Asymptoten eintragen; Plausibilität prüfen.

Blatt 2 von 4 · Kriterien, Tangenten und Funktionenscharen

Extrempunkte und Monotonie

Notwendig und hinreichend

Notwendig (innere Stelle, f differenzierbar): f'(x₀) = 0.

f'(x₀) = 0 und f''(x₀) < 0 → Hochpunkt
f'(x₀) = 0 und f''(x₀) > 0 → Tiefpunkt

Bei f''(x₀) = 0 entscheidet der Vorzeichenwechsel von f': + → − Hochpunkt, − → + Tiefpunkt, kein VZW → Sattelpunkt.

Globale Extrema: lokale Extremwerte mit den Randwerten bzw. dem Grenzverhalten vergleichen.

Monotonie und Krümmung

  • f' > 0 auf einem Intervall ⇒ f streng monoton steigend; f' < 0 ⇒ streng monoton fallend.
  • Umkehrung gilt nicht: f(x) = x³ ist streng monoton steigend, obwohl f'(0) = 0.
  • f'' > 0: linksgekrümmt (konvex); f'' < 0: rechtsgekrümmt (konkav).
  • Monotonieintervalle zwischen den Nullstellen von f' (und Definitionslücken) ablesen.

Wendepunkte, Tangente und Normale

Wendepunkt W(x₀ | f(x₀))

Notwendig: f''(x₀) = 0.

f''(x₀) = 0 und f'''(x₀) ≠ 0 → Wendestelle

Ist f'''(x₀) = 0, entscheidet der Vorzeichenwechsel von f''. Gilt zusätzlich f'(x₀) = 0: Sattelpunkt (Wendepunkt mit waagerechter Tangente).

Am Wendepunkt ist die Steigung lokal am größten bzw. kleinsten (z. B. „stärkste Zunahme“).

Geraden am Graphen im Punkt (x₀ | f(x₀))

Tangente: y = f'(x₀)·(x − x₀) + f(x₀)
Normale: y = −1/f'(x₀) · (x − x₀) + f(x₀)

Normale nur für f'(x₀) ≠ 0; bei waagerechter Tangente ist die Normale x = x₀. Senkrecht: m₁·m₂ = −1.

Tangente von einem Punkt P außerhalb: Tangente in allgemeiner Stelle u aufstellen, P einsetzen, nach u lösen.

Merke: f'(x₀) = 0 allein beweist kein Extremum, f''(x₀) = 0 allein keinen Wendepunkt. Immer ein hinreichendes Kriterium angeben und die y-Koordinate berechnen.

Funktionenscharen

Rechnen mit Parameter

  • Der Parameter (z. B. a) ist beim Ableiten eine Konstante.
  • Fallunterscheidungen beachten: a > 0, a = 0, a < 0 (z. B. bei √a, Division durch a, Vorzeichen von f'').
  • „Gemeinsame Punkte aller Graphen“: fa(x) = fb(x) für a ≠ b lösen – oder den Term so umformen, dass der Parameter wegfällt.
  • „Für welches a …“: Bedingung aufstellen und nach a auflösen.

Ortskurve (Ortslinie)

  1. Extrem- bzw. Wendepunkt in Abhängigkeit von a: x = x(a), y = y(a).
  2. x = x(a) nach a auflösen.
  3. In y = y(a) einsetzen → Gleichung y = … nur in x.

Beispiel: fa(x) = x³ − a·x, a > 0: fa'(x) = 3x² − a = 0 ⇒ x = ±√(a/3), also a = 3x². Einsetzen: y = x³ − 3x²·x = −2x³. Alle Extrempunkte liegen auf y = −2x³.

Linearität: ∫(a·f + b·g) dx = a·∫f dx + b·∫g dx.

Verkettungen

∫ g'(x)·f(g(x)) dx = F(g(x)) + C

Erkennbar daran, dass die innere Ableitung als Faktor dasteht. Beispiel: ∫ 2x·ex² dx = ex² + C.

∫ u'(x)/u(x) dx = ln|u(x)| + C

Falls im Unterricht behandelt – partielle Integration: ∫ u'·v dx = u·v − ∫ u·v' dx (z. B. für x·ex).

Probe: F ableiten – es muss f herauskommen.

Hauptsatz der Differential- und Integralrechnung

f stetig auf [a; b], F' = f  ⇒  ∫ab f(x) dx = F(b) − F(a) = [F(x)]ab
  • Das Integral ist eine Flächenbilanz: Flächen oberhalb der x-Achse zählen positiv, unterhalb negativ.
  • Grenzen vertauschen ändert das Vorzeichen: ∫ von b bis a = −∫ von a bis b. Intervalle lassen sich aneinanderhängen: ∫ab + ∫bc = ∫ac.

Flächen

Zwischen Graph und x-Achse

Nullstellen im Intervall bestimmen, dort aufteilen, Beträge der Teilintegrale addieren:

A = |∫ax₁ f dx| + |∫x₁b f dx|

Zwischen zwei Graphen

A = ∫ab (f(x) − g(x)) dx,  f oberhalb von g

Grenzen = Schnittstellen (f(x) = g(x)). Bei mehreren Schnittstellen aufteilen und Beträge addieren. Die x-Achse spielt dabei keine Rolle.

Typischer Fehler: ∫ab f dx ist nicht automatisch der Flächeninhalt. Bei Vorzeichenwechsel aufteilen, sonst heben sich Teilflächen auf.

Integralfunktion, Mittelwert, Volumen

Integralfunktion

Ia(x) = ∫ax f(t) dt  ⇒  Ia'(x) = f(x),  Ia(a) = 0

I steigt, wo f > 0; Extremstellen von I bei Vorzeichenwechseln von f; Wendestellen von I bei Extremstellen von f.

Mittelwert: m = 1/(b − a) · ∫ab f(x) dx

Uneigentliche Integrale & Rotation

∫a∞ f(x) dx = limz→∞ ∫az f(x) dx

Erst mit fester Grenze z rechnen, dann den Grenzwert bilden. Existiert er, hat die unbegrenzte Fläche einen endlichen Inhalt.

Rotation um die x-Achse: V = π · ∫ab (f(x))² dx

Rotationskörper nur, falls im Unterricht behandelt.

Blatt 4 von 4 · Optimierung, Wachstum, Rekonstruktion und Checkliste

Optimierungsaufgaben (Extremwertprobleme)

  1. Zielgröße festlegen: Was soll maximal/minimal werden? Formel mit (zunächst) mehreren Variablen.
  2. Nebenbedingung nach einer Variablen auflösen und einsetzen → Zielfunktion in einer Variablen.
  3. Definitionsbereich aus dem Sachkontext (Längen > 0 usw.).
  4. Ableiten, f' = 0, hinreichendes Kriterium; Randwerte vergleichen.
  5. Alle gesuchten Größen berechnen, Antwortsatz mit Einheit.

Wachstumsmodelle

Exponentielles Wachstum / Zerfall

f(t) = c·ek·t,  f'(t) = k·f(t)
  • c = f(0): Anfangswert; k > 0 Wachstum, k < 0 Zerfall.
  • Aus einem zweiten Wert f(t₁) = y: k = ln(y/c) / t₁.
  • Verdopplungszeit T₂ = ln 2 / k; Halbwertszeit T½ = ln 2 / |k|.
  • Wachstumsfaktor pro Zeiteinheit: q = ek, also k = ln q (z. B. +5 % → q = 1,05).

Beschränktes Wachstum

f(t) = S − (S − f(0))·e−k·t,  k > 0
f'(t) = k·(S − f(t))

S ist die Schranke (Sättigungswert); die Änderungsrate ist proportional zum Restbestand S − f(t). Beispiel: Abkühlung auf Raumtemperatur.

Probe: f(0) einsetzen, f(t) → S für t → ∞.

Weitere Standardaufgaben

Rekonstruktion („Steckbriefaufgabe“)

Ansatz wählen (z. B. f(x) = ax³ + bx² + cx + d: 4 Unbekannte → 4 Bedingungen) und übersetzen:

  • Punkt P(a | y): f(a) = y
  • Extremum bei a: f'(a) = 0 · Steigung m bei a: f'(a) = m
  • Wendestelle bei a: f''(a) = 0
  • Symmetrie zur y-Achse: nur gerade Exponenten

LGS lösen, danach prüfen, ob die Bedingungen wirklich erfüllt sind (z. B. tatsächlich ein Extremum).

Änderungsrate und Bestand

Bestand(b) = Bestand(a) + ∫ab r(t) dt
  • Mittlere Änderungsrate: (f(b) − f(a)) / (b − a); momentane: f'(x₀).
  • Einheiten: Liter/min · min = Liter.
  • Bestand maximal, wo die Rate r von + nach − wechselt.
  • Schnittpunkte f(x) = g(x); Berührung: f(a) = g(a) und f'(a) = g'(a).

Checkliste für jede Aufgabe

  • Definitionsbereich und Sachkontext beachten; Lösungen auf Zulässigkeit prüfen.
  • Extrem- und Wendestellen: hinreichendes Kriterium angeben und Punktkoordinaten berechnen.
  • Integral: Flächenbilanz oder Flächeninhalt? Nullstellen und Schnittstellen als Grenzen beachten.
  • Stammfunktion durch Ableiten kontrollieren.
  • Bei Scharen: Fallunterscheidung für den Parameter nicht vergessen.
  • Taschenrechner bei sin/cos auf RAD stellen; exakt rechnen, erst am Ende runden; Antwortsatz mit Einheit.

Notation: C ist die Integrationskonstante; bei bestimmten Integralen fällt sie in F(b) − F(a) weg.
