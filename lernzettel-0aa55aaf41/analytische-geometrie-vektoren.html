Analytische Geometrie: Vektorarten

Blatt 1 von 4 · Punkt oder Pfeil? Ortsvektor, Verbindungsvektor und Spezialfälle

Grundidee: Ein Vektor ist eine Verschiebung (Richtung + Länge), kein fester Pfeil. Alle gleich langen, gleich gerichteten Pfeile sind derselbe Vektor. Ob ein Vektor als Ortsvektor, Richtungsvektor oder Normalenvektor gilt, hängt davon ab, wofür man ihn benutzt. Rechnen tut man mit allen gleich.

Ortsvektor OP

Was: Pfeil vom Ursprung O zum Punkt P. Er hat dieselben Koordinaten wie der Punkt: P(3|−1|2) ⇒ OP = (3 | −1 | 2).

Wofür:

  • Stützvektor in Geraden- und Ebenengleichungen („wo fange ich an?“)
  • Punkte als Vektoren einsetzen, z. B. bei der Punktprobe
  • Neue Punkte berechnen: OQ = OP + (Verschiebung)
  • Mittelpunkt OM = ½(OA + OB), Schwerpunkt OS = ⅓(OA + OB + OC)

Nur der Ortsvektor ist an einen festen Startpunkt (O) gebunden.

Verbindungsvektor AB

AB = OB − OA  („Spitze minus Fuß“)

Wofür:

  • Abstand zweier Punkte = Länge |AB|
  • wird zum Richtungsvektor der Geraden AB bzw. zum Spannvektor einer Ebene
  • Figuren prüfen: Parallelogramm ⇔ AB = DC; rechter Winkel ⇔ AB · AC = 0
  • Kollinearität: A, B, C auf einer Geraden ⇔ AC = r · AB
  • Verschiebung: Punkt D = C + AB

Spezielle Vektoren

Einheitsvektor a₀ = a / |a|Länge 1, gleiche Richtung. Wofür: Hesse-Normalform; Punkt in gegebenem Abstand: Q = P + s · a₀ hat von P genau den Abstand s.
Gegenvektor −aGleiche Länge, umgekehrte Richtung: BA = −AB. Wofür: Richtung umdrehen, z. B. Spiegelung „auf die andere Seite“.
Nullvektor 0 = (0|0|0)Hat keine Richtung. Darf nie Richtungs- oder Normalenvektor sein. a × b = 0 ⇔ a und b sind parallel.
Vielfache r · aGleiche Richtung (r > 0) bzw. Gegenrichtung (r < 0), Länge |r|·|a|. Richtungs- und Normalenvektoren darf man beliebig kürzen oder erweitern: (6|−3|−6) → (2|−1|−2).

Richtung, Spannweite, Senkrechte

Blatt 2 von 4 · Richtungsvektor, Spannvektoren, Normalenvektor und Kreuzprodukt

Richtungsvektor u (Gerade)

g: x = OP + t · u  (u ≠ 0)

Gibt an, in welche Richtung die Gerade läuft. Jedes Vielfache r·u (r ≠ 0) beschreibt dieselbe Gerade.

Wofür:

  • Lage zweier Geraden: u ∥ v? → parallel oder identisch, sonst schneidend oder windschief
  • Winkel zwischen Geraden: cos α = |u · v| / (|u|·|v|)
  • Gerade ∥ Ebene ⇔ u · n = 0
  • Gerade ⟂ Ebene ⇔ u ∥ n (Lotgerade: u = n)
  • Lotfußpunkt auf g: Bedingung (X − H) · u = 0

Spannvektoren u, v (Ebene)

E: x = OP + r · u + s · v

Zwei Richtungsvektoren, die nicht parallel sein dürfen (linear unabhängig). Sie „spannen“ die Ebene auf.

Wofür:

  • Ebene durch drei Punkte: u = AB, v = AC
  • Normalenvektor bestimmen: n = u × v
  • Ebene durch g parallel zu h: Spannvektoren = Richtungsvektoren von g und h
  • Flächen: |u × v| = Parallelogramm, ½|u × v| = Dreieck

Normalenvektor n

Steht senkrecht auf der Ebene, also auf allen Spannvektoren. Er beschreibt die „Stellung“ der Ebene.

E: n₁x₁ + n₂x₂ + n₃x₃ = d  ⇒  n = (n₁ | n₂ | n₃)

Bestimmen: aus der Koordinatenform ablesen, oder n = u × v, oder das LGS n · u = 0, n · v = 0 lösen (eine Koordinate frei wählen).

Wofür der Normalenvektor?

  • Koordinatenform aufstellen: d = n · OP
  • Abstand Punkt–Ebene: |n · OX − d| / |n|
  • Lotgerade durch X: x = OX + t · n (Lotfußpunkt, Spiegelung)
  • Winkel Ebene–Ebene (cos, mit n₁, n₂) und Gerade–Ebene (sin, mit n und u)
  • Lage: n₁ ∥ n₂ ⇒ Ebenen parallel oder identisch; u · n = 0 ⇒ g ∥ E
Kreuzprodukt a × b = (a₂b₃ − a₃b₂ | a₃b₁ − a₁b₃ | a₁b₂ − a₂b₁) liefert einen Vektor, der senkrecht auf a und b steht (→ Normalenvektor) und dessen Länge die Parallelogrammfläche ist. Probe: Skalarprodukt mit a und b muss 0 sein.

Beziehungen und Rechenoperationen

Blatt 3 von 4 · Was sagt welche Rechnung über die Vektoren aus?

Wie stehen zwei oder drei Vektoren zueinander?

parallel (kollinear)a = r · b (jede Koordinate liefert dasselbe r) ⇔ a × b = 0. → Geraden parallel, Punkte auf einer Geraden, Ebenen parallel.
orthogonal (senkrecht)a · b = 0. → rechter Winkel, Lot, Normalenvektor prüfen, „steht senkrecht auf“.
komplanar (in einer Ebene)Einer ist Linearkombination der anderen: c = r · a + s · b ⇔ (a × b) · c = 0. → Vier Punkte in einer Ebene? Zwei Geraden schneidend (statt windschief)?
linear unabhängigr · a + s · b + t · c = 0 hat nur die Lösung r = s = t = 0. Drei unabhängige Vektoren bilden eine Basis des Raums.

Was liefert welche Operation?

Addition und Vielfache → Vektor

  • Punkte verschieben: OQ = OP + a
  • Punkte auf Geraden und Ebenen erzeugen (Parameter einsetzen)
  • Mittelpunkt, Schwerpunkt, Teilpunkte: OT = OA + ⅓ · AB
  • Spiegeln: P' = P + 2 · PF (F = Lotfußpunkt bzw. Spiegelzentrum)

Betrag |a| → Zahl (Länge)

|a| = √(a₁² + a₂² + a₃²)
  • Abstand zweier Punkte = |AB|
  • Seitenlängen, Umfang, gleichschenklig?
  • Normieren (Einheitsvektor)

Skalarprodukt a · b → Zahl

a · b = a₁b₁ + a₂b₂ + a₃b₃ = |a| · |b| · cos φ
  • = 0 ⇒ senkrecht
  • Winkel zwischen Vektoren, Geraden, Ebenen
  • Koordinatenform: n · x = d
  • Vorzeichen: > 0 spitzer Winkel, < 0 stumpfer Winkel

Kreuzprodukt a × b → Vektor

  • Richtung: senkrecht auf a und b → Normalenvektor; Richtung der Schnittgeraden zweier Ebenen: n₁ × n₂
  • Länge: Parallelogrammfläche, Dreieck = Hälfte
  • = 0 ⇒ a ∥ b

Spatprodukt (a × b) · c → Zahl

Betrag = Volumen des Spats; dreiseitige Pyramide (Tetraeder) = ⅙ davon. = 0 ⇒ komplanar.

Typische Verwechslung: Punkte und Vektoren nicht mischen. „A + B“ ergibt keinen sinnvollen Punkt, ½(OA + OB) schon (Mittelpunkt). Und: Verbindungsvektor immer „Ende minus Anfang“. AB = B − A, nicht A − B.

Durchgerechnetes Beispiel

Gegeben: A(1|1|1), B(3|3|2), C(2|−1|3) und die Spitze S(7|0|−3) einer Pyramide ABCS.

  1. Verbindung AB = (2|2|1), AC = (1|−2|2); |AB| = |AC| = √9 = 3.
  2. Skalarprodukt AB · AC = 2 − 4 + 2 = 0 ⇒ rechter Winkel bei A.
  3. Normale AB × AC = (6|−3|−6), gekürzt n = (2|−1|−2), |n| = 3.
  4. Ortsvektor d = n · OA = 2 − 1 − 2 = −1 ⇒ E: 2x₁ − x₂ − 2x₃ = −1. Probe mit B und C: −1 ✓.
  5. Einheitsvektor AB₀ = ⅓(2|2|1). Punkt auf dem Strahl AB im Abstand 6 von A: OA + 6 · AB₀ = (5|5|3).
  1. Dreiecksfläche: ½ · |AB × AC| = ½ · 9 = 4,5.
  2. Höhe = Abstand S–E: |2·7 − 0 − 2·(−3) − (−1)| / 3 = 21/3 = 7.
  3. Volumen: ⅓ · 4,5 · 7 = 10,5. Kontrolle Spatprodukt: (AB × AC) · AS = (6|−3|−6) · (6|−1|−4) = 63, ⅙ · 63 = 10,5 ✓.
  4. Lotgerade x = (7|0|−3) + t·(2|−1|−2) in E: 20 + 9t = −1 ⇒ t = −7/3 ⇒ Lotfußpunkt F(7/3 | 7/3 | 5/3).
  5. Schwerpunkt des Dreiecks: ⅓(OA + OB + OC) = (2|1|2).
Merksatz: Ortsvektor = wo?  ·  Richtungs- bzw. Verbindungsvektor = wohin und wie weit?  ·  Normalenvektor = senkrecht zu was?  ·  Einheitsvektor = genau 1 lang
