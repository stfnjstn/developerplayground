Abstände berechnen

Blatt 1 von 2 · Sechs Fälle mit Skizze, Formel und Vorgehen. Abstand = immer die kürzeste Verbindung, und die steht senkrecht.

1Punkt – Punkt

d(P, Q) = |PQ| = √((q₁−p₁)² + (q₂−p₂)² + (q₃−p₃)²)

Verbindungsvektor bilden („Ende minus Anfang“), dann seinen Betrag.

2Punkt – Gerade

g: x = OA + t · u

d(P, g) = |AP × u||u|

Lotfußpunkt-Weg: F = A + t·u allgemein ansetzen, FP · u = 0 nach t lösen, d = |FP|.

3Punkt – Ebene

E: n₁x₁ + n₂x₂ + n₃x₃ = dE

d(P, E) = |n₁p₁ + n₂p₂ + n₃p₃ − dE||n|

Punkt in die linke Seite einsetzen, Betrag, durch |n| teilen. Lotgerade x = OP + t·n mit E schneiden ⇒ Lotfußpunkt F.

4Gerade – Gerade

g: x = OA + s·u, h: x = OB + t·v. Zuerst Lage prüfen!

  • schneidend: d = 0
  • parallel: d = Abstand eines Punkts B von g (→ Fall 2)
  • windschief: d = |AB · (u × v)||u × v|

Lotfußpunkte gesucht: G = A + su, H = B + tv mit GH·u = 0 und GH·v = 0 (LGS), d = |GH|.

5Gerade – Ebene

Ein Abstand > 0 existiert nur, wenn g ∥ E. Test: n · u = 0 (und A ∉ E). Sonst schneidet g die Ebene oder liegt darin ⇒ d = 0.

d(g, E) = d(A, E)  mit beliebigem Punkt A ∈ g (→ Fall 3)

6Ebene – Ebene

Abstand > 0 nur bei parallelen Ebenen (n₁ ∥ n₂, nicht identisch). Sonst Schnittgerade ⇒ d = 0.

d(E₁, E₂) = d(P, E₁)  mit beliebigem P ∈ E₂ (→ Fall 3)

Abkürzung: Erst beide Gleichungen auf denselben Normalenvektor bringen, dann d = |d₁ − d₂| / |n|.

Vorgehen und Beispiele

Blatt 2 von 2 · Erst die Lage, dann die Formel. Je ein durchgerechnetes Beispiel pro Fall.

Entscheidungshilfe

Punkt – Punktimmer direkt: |PQ|
Punkt – GeradeLiegt P auf g? → 0. Sonst Kreuzprodukt-Formel oder Lotfußpunkt.
Punkt – EbenePunktprobe = 0? → P liegt in E. Sonst Abstandsformel bzw. HNF.
Gerade – Geradeu ∥ v? → identisch (0) oder parallel (Fall 2). Sonst: Spatprodukt = 0 → schneidend (0), ≠ 0 → windschief (Formel).
Gerade – Ebenen · u ≠ 0 → Schnitt (0). = 0 → Stützpunkt einsetzen: in E (0) oder parallel (Fall 3).
Ebene – Ebenen₁ ∦ n₂ → Schnittgerade (0). Sonst: identisch (0) oder parallel (Fall 3).

Beispiele

1Punkt – Punkt

P(1|2|3), Q(3|−2|7): PQ = (2|−4|4), d = √(4 + 16 + 16) = √36 = 6.

2Punkt – Gerade

g: x = (1|0|2) + t·(2|1|−2), P(5|5|4).

AP = (4|5|2), AP × u = (−12|12|−6), Betrag 18; |u| = 3 ⇒ d = 18/3 = 6.

Lotfuß: AP·u = 9 = t·u·u = 9t ⇒ t = 1 ⇒ F(3|1|0), |FP| = |(2|4|4)| = 6 ✓

3Punkt – Ebene

E: 2x₁ − x₂ + 2x₃ = 5, P(5|−1|6).

2·5 + 1 + 2·6 = 23 ⇒ d = |23 − 5| / √(4 + 1 + 4) = 18/3 = 6.

Lotgerade (5|−1|6) + t(2|−1|2) in E: 23 + 9t = 5 ⇒ t = −2 ⇒ F(1|1|2).

4Gerade – Gerade (windschief)

g: (1|0|0) + s(1|1|0), h: (0|1|3) + t(1|−1|0).

u × v = (0|0|−2), AB = (−1|1|3), AB·(u×v) = −6 ≠ 0 ⇒ windschief. d = |−6| / 2 = 3.

Lotfußpunkte: s = 0, t = 1 ⇒ G(1|0|0), H(1|0|3) ✓

5Gerade – Ebene

E wie in 3, g: x = (5|−1|6) + t·(1|2|0).

n · u = 2 − 2 + 0 = 0 ⇒ g ∥ E. Abstand des Stützpunkts (5|−1|6) = 6 (siehe 3).

6Ebene – Ebene

E₁: 2x₁ − x₂ + 2x₃ = 5, E₂: 4x₁ − 2x₂ + 4x₃ = −8.

E₂ durch 2 teilen: 2x₁ − x₂ + 2x₃ = −4 ⇒ gleicher n, parallel. d = |5 − (−4)| / 3 = 3.

Falle: Ohne Teilen würde man fälschlich |5 − (−8)| rechnen.

Checkliste: Betrag nicht vergessen (Abstände sind nie negativ) · durch die Länge des Normalen- bzw. Richtungsvektors teilen · bei Gerade–Ebene und Ebene–Ebene zuerst Parallelität prüfen · Ergebnis mit Lotfußpunkt kontrollieren, wenn Zeit ist.
