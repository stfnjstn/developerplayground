Blatt 1 von 4 · Vektoren, Geraden und Abstände

Vektor-Werkzeugkasten

Für a = (a₁|a₂|a₃), b = (b₁|b₂|b₃):

|a| = √(a₁² + a₂² + a₃²)  ·  |AB| = |B − A|
a · b = a₁b₁ + a₂b₂ + a₃b₃
cos(φ) = a · b / (|a| |b|),  0° ≤ φ ≤ 180°
a × b = (a₂b₃ − a₃b₂ | a₃b₁ − a₁b₃ | a₁b₂ − a₂b₁)
  • Skalarprodukt: a ⟂ b ⇔ a · b = 0.
  • Vektorprodukt: steht senkrecht auf a und b; |a × b| = Parallelogrammfläche.
  • Spatprodukt: |(a × b) · c| = Spatvolumen; = 0 ⇔ a, b, c komplanar.

Probe nach dem Kreuzprodukt: (a × b) · a = 0 und (a × b) · b = 0.

Geradengleichung

g: x = p + t·u,  t ∈ ℝ

p ist Ortsvektor eines Punkts auf g (Stützvektor), u ≠ 0 ein Richtungsvektor. Gerade durch A und B: x = A + t·(B − A).

Schnittwinkel: cos(α) = |u · v| / (|u| |v|)

Mit Betrag erhält man den Schnittwinkel 0° ≤ α ≤ 90°. Ohne Betrag erhält man den Winkel zwischen den Vektoren (0° bis 180°); ist er stumpf, ist der Schnittwinkel 180° − φ.

Weitere Grundlagen

  • Mittelpunkt: M = ½(A + B).
  • Kollinear (A, B, C auf einer Geraden): B − A und C − A sind Vielfache voneinander.
  • Punktprobe Gerade: P = p + t·u lösen; jede Zeile muss dasselbe t ergeben.

Lagebeziehung zweier Geraden

1. Richtungen vergleichen: u = λ·v?Ja → parallel oder identisch: Punktprobe mit p in h. Liegt p auf h → identisch, sonst echt parallel.
2. Nicht parallel: p + t·u = q + s·v lösenGenau eine Lösung (t|s) → schneidend, t in g einsetzen ergibt S. Keine Lösung → windschief.

Kurztest für nicht parallele Geraden: (q − p) · (u × v) = 0 ⇔ schneidend, ≠ 0 ⇔ windschief. Wichtig: Bei 3 Gleichungen mit 2 Unbekannten t, s mit zwei Zeilen lösen und die dritte Zeile prüfen.

Abstände zu Geraden

Punkt X zu g: x = p + t·u

d(X,g) = |(X − p) × u| / |u|

Lotfußpunkt-Verfahren: allgemeiner Punkt H = p + t·u; Bedingung (X − H) · u = 0 liefert t; dann d(X,g) = |X − H|.

Zwei Geraden g: p + t·u, h: q + s·v

schneidend: d(g,h) = 0
parallel: d(g,h) = |(q − p) × u| / |u|
windschief: d(g,h) = |(q − p) · (u × v)| / |u × v|

Parallel = Abstand eines Punkts Q von g. Windschief, wenn auch die Lotfußpunkte gesucht sind: G = p + t·u, H = q + s·v mit (H − G) · u = 0 und (H − G) · v = 0 (LGS für t, s), dann d = |H − G|.

Ebenen und Gerade–Ebene

Blatt 2 von 4 · Darstellungen erkennen und passend einsetzen

Ebenengleichungen

Parameterform

E: x = p + r·u + s·v

p liegt in E; u und v sind linear unabhängige (nicht parallele) Spannvektoren.

Gut fürEbene aus drei Punkten: x = A + r·(B − A) + s·(C − A).

Normalenform

E: n · (x − p) = 0

n ≠ 0 steht senkrecht auf E; p liegt in E.

Gut fürEbene „durch P senkrecht zu …“, Lotgeraden.

Koordinatenform

E: n₁x₁ + n₂x₂ + n₃x₃ = d,  n = (n₁|n₂|n₃)

Normalenvektor direkt ablesen. Aus der Parameterform: n = u × v, dann d = n · p.

Gut fürPunktprobe, Schnitte, Abstände, Spurpunkte.

Hesse-Normalform (HNF)

E: n₀ · (x − p) = 0,  n₀ = n / |n|

Setzt man einen Punkt X für x ein, ist n₀ · (X − p) sein orientierter Abstand (Vorzeichen = Seite der Ebene); der Betrag ist d(X,E).

Umformen: Parameterform → n = u × v → d = n · p → Koordinatenform n · x = d. Koordinatenform ÷ |n| ergibt die HNF. Eine Ebene ist durch drei nicht kollineare Punkte eindeutig bestimmt.

Spurpunkte und Spurgeraden

Ebene E: n₁x₁ + n₂x₂ + n₃x₃ = d

Achsenschnittpunkte: zwei Koordinaten 0 setzen, z. B. S₁(d/n₁ | 0 | 0), S₂(0 | d/n₂ | 0), S₃(0 | 0 | d/n₃) (falls nᵢ ≠ 0). Verbindungen der Spurpunkte = Spurgeraden (gut zum Zeichnen).

Gerade g: x = p + t·u

Spurpunkt mit der x₁x₂-Ebene: dritte Koordinate = 0 setzen, t bestimmen, einsetzen. Analog x₁x₃-Ebene (x₂ = 0) und x₂x₃-Ebene (x₁ = 0).

Gerade und Ebene

Für g: x = p + t·u und E: n · x = d wird die Gerade in die Koordinatenform eingesetzt:

n · (p + t·u) = d  ⇒  t = (d − n · p) / (n · u)  (falls n · u ≠ 0)

Lage und Schnittpunkt

  • n · u ≠ 0: genau ein Schnittpunkt; t berechnen und in g einsetzen.
  • n · u = 0: g ∥ E. Punktprobe mit p: n · p = d ⇒ g liegt in E; sonst echt parallel.
  • Beim Einsetzen sichtbar: eindeutige Lösung t → Schnitt; 0 = 0 → g in E; Widerspruch (z. B. 0 = 5) → parallel.

Winkel und Abstand

sin(α) = |n · u| / (|n| |u|)

α ist der Schnittwinkel zwischen Gerade und Ebene (0° bis 90°) – also 90° minus der spitze Winkel zwischen u und n. Daher sin statt cos!

Bei echter Parallelität: d(g,E) = |n · p − d| / |n|.

Häufiger Fehler: Aus n · (x − p) = 0 folgt n · x = n · p, also ist die rechte Seite d = n · p – nicht 0. Nur Ebenen durch den Ursprung haben d = 0.

Abstände, Spiegelungen & Ebene–Ebene

Blatt 3 von 4 · Lotfußpunkte, Flächen, Volumen und Schnittgeraden

Punkt–Ebene

Abstand per Formel

E: n · x = d  ⇒  d(X,E) = |n · X − d| / |n|

Punkt einsetzen, Betrag nehmen, durch |n| teilen. Bei HNF entfällt der Nenner.

Lotfußpunkt & Spiegelpunkt

  1. Lotgerade l: x = X + t·n.
  2. l mit E schneiden → t₀ und Lotfußpunkt F.
  3. d(X,E) = |F − X|.
  4. Spiegelpunkt: X' = X + 2·(F − X), also t = 2t₀ in l.
Beispiel: E: 2x₁ − x₂ + 2x₃ = 6, X(4|1|5).  n · X = 8 − 1 + 10 = 17, |n| = 3 ⇒ d(X,E) = |17 − 6| / 3 = 11/3.
Lot: (4+2t) · 2 − (1−t) + (5+2t) · 2 = 6 ⇒ 17 + 9t = 6 ⇒ t₀ = −11/9 ⇒ F(14/9 | 20/9 | 23/9), X'(−8/9 | 31/9 | 1/9).

Weitere Spiegelungen

Punkt an Punkt

X' = 2M − X

M ist Mittelpunkt von X und X'.

Punkt an Gerade g

Lotfußpunkt F auf g bestimmen ((X − F) · u = 0, siehe Blatt 1), dann X' = 2F − X.

Flächen und Volumen

Dreieck ABC: A = ½ · |(B − A) × (C − A)|
Parallelogramm ABCD: A = |(B − A) × (D − A)|

Ohne Kreuzprodukt: A = ½ · g · h, Höhe h z. B. als Abstand Punkt–Gerade.

Pyramide: V = ⅓ · G · h
Tetraeder ABCD: V = ⅙ · |((B−A) × (C−A)) · (D−A)|

h = Abstand der Spitze von der Grundflächen-Ebene.

Zwei Ebenen E₁, E₂

Lage

  • n₁, n₂ nicht parallel → Schnittgerade.
  • n₁ = λ·n₂ → identisch oder echt parallel: Punkt von E₂ in E₁ einsetzen.
Schnittwinkel: cos(α) = |n₁ · n₂| / (|n₁| |n₂|)

Parallele Ebenen: d(E₁,E₂) = |n₁ · P₂ − d₁| / |n₁| mit beliebigem P₂ ∈ E₂.

E₁ ⟂ E₂ ⇔ n₁ · n₂ = 0.

Schnittgerade bestimmen

  1. Beide Koordinatenformen als LGS (2 Gleichungen, 3 Unbekannte).
  2. Eine Variable eliminieren, eine Variable als Parameter setzen (z. B. x₃ = t).
  3. Übrige Variablen durch t ausdrücken → g: x = p + t·u.

Kontrolle: u ∥ n₁ × n₂, und p erfüllt beide Ebenengleichungen.

Alternative: Parameterform von E₂ in Koordinatenform von E₁ einsetzen → Beziehung zwischen r und s → in E₂ einsetzen.

Lage und Winkel auf einen Blick

Gerade–Geradeu ∥ v? → identisch / echt parallel (Punktprobe). Sonst gleichsetzen → schneidend / windschief. Winkel: cos(α) = |u·v| / (|u||v|).
Gerade–Ebenen · u ≠ 0 → Schnittpunkt; n · u = 0 → parallel oder in E (Punktprobe). Winkel: sin(α) = |n·u| / (|n||u|).
Ebene–Ebenen₁ ∦ n₂ → Schnittgerade; n₁ ∥ n₂ → parallel oder identisch (Punktprobe). Winkel: cos(α) = |n₁·n₂| / (|n₁||n₂|).

Welche Methode passt?

Zum Aufstellen

  • Gerade durch A, B: x = A + t·(B − A).
  • Ebene durch A, B, C: Parameterform; n = (B − A) × (C − A) für die Koordinatenform.
  • Ebene durch P mit Normalenvektor n: n · (x − P) = 0.
  • Ebene, die g enthält und ∥ h ist: Stützpunkt von g, Spannvektoren u und v.
  • Ebene senkrecht zu g durch P: n = u.

Zum Rechnen

  • Gerade–Gerade: gleichsetzen (LGS mit Probe in 3. Zeile).
  • Gerade–Ebene: Gerade in Koordinatenform einsetzen.
  • Ebene–Ebene: LGS der Koordinatenformen oder Parameterform in Koordinatenform.
  • Winkel: Skalarprodukt. Normalenvektor aus zwei Richtungen: Vektorprodukt.
  • Abstand = immer kürzeste Strecke ⇒ senkrecht (Lot).

Mini-Check vor der Abgabe

  • Ist jeder Richtungs-/Normalenvektor ≠ 0? Sind die zwei Spannvektoren einer Ebene nicht parallel?
  • Kreuzprodukt geprüft? (n · u = 0 und n · v = 0)
  • Bei „parallel“ auch „identisch“ geprüft (Punktprobe)?
  • Schnittpunkt in alle Ausgangsgleichungen eingesetzt? Beim Geraden-LGS die dritte Zeile geprüft?
  • Winkel: Betrag für den Schnittwinkel (≤ 90°); Gerade–Ebene mit sin, sonst cos. Taschenrechner auf DEG?
  • Abstand: Betrag gesetzt und durch die Länge des Normalen- bzw. Richtungsvektors geteilt?
  • Exakte Werte (Brüche, Wurzeln) möglichst lange behalten; erst am Ende runden. Antwortsatz!

Symbolik: x ist der Ortsvektor eines beliebigen Punkts; p, q sind Stützvektoren; u, v sind Richtungsvektoren; n, n₁, n₂ sind Normalenvektoren; d (ohne Klammer) ist die rechte Seite der Koordinatenform, d(·,·) ein Abstand. Koordinaten: x₁, x₂, x₃ (entspricht x, y, z).
