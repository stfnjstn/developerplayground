## Start Page

![Start Page](/assets/ETMEditor/StartPage.jpg)

The editor opens on its start page:

- **Create New Level Pack**: Asks for a name and a file name and opens the new pack.
- **Import Level Packs**: Picks an `.etdm` (or `.json`) level pack from the Files app and adds it to your packs.
- **Recent Level Packs**: Your packs, newest first, with their name, file name and number of levels. Tap one to open it; swipe it to the left to delete it.
- The **(i)** button opens the about page.

Creating or opening a level pack takes you to the [Levelpack Main Screen](/ETMEditorTutorials/ETMEditorTutorial_DetailDialog).
